# Chrome Web Store listing copy

## Title

Discord Direct Links

## Short description

Skip Discord web's confirmation for ordinary external links. Leaves download controls alone.

## Detailed description

Open ordinary external links from Discord web without Discord's external-link confirmation.

Discord Direct Links leaves the browser's normal link navigation in place, including the link's target and standard keyboard or modifier-key behavior. It works on Discord's stable, PTB and Canary websites. There is no popup or settings page. Install it and reload Discord tabs.

IMPORTANT: This removes a phishing safeguard. A link's visible text can hide its real destination. Check where a link leads before opening it. This extension does not check whether links are safe and does not bypass Chrome Safe Browsing or browser download warnings.

It leaves Discord links, recognized attachments, download controls, file-looking URLs and links inside existing dialogs alone. Download detection is conservative, so some ordinary links may still show a confirmation. An opaque URL can redirect or return a file; the extension does not inspect responses and cannot identify every download.

Privacy: clicked URLs, click events and relevant page-element attributes are processed only in your browser to decide how to handle the link. The extension does not store this data or send it to the developer. It has no analytics, advertising or background service. Destination websites still receive normal browser requests when you open links.

Site access is limited to https://discord.com/*, https://ptb.discord.com/* and https://canary.discord.com/*. It needs that access to handle link clicks on Discord web. It does not request extension API permissions such as tabs, history, cookies, storage or downloads.

This is a Chrome extension for Discord web, not a Discord desktop-client modification. Discord can change its web interface and affect compatibility. Discord Direct Links is not affiliated with or endorsed by Discord.

The listing screenshots show the real installed extension running against a clearly labeled local test fixture with synthetic content, not a signed-in Discord conversation. The status panel belongs to the demo, not the extension.
